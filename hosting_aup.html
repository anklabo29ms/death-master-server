SUMMARY FOR NETWORK SECURITY AUDITORS

1. What is this application doing on this server?
This application (`server.py`) is an orchestrator that aggregates public, freely available proxy lists from open repositories, indexes them in memory, and serves work batches to authenticated remote worker nodes (`client.py`). It acts as a passive central coordinator, similar to a Git server or MQTT broker.
2. Does this server communicate with the proxies?
No. The server does not connect to the proxy IP addresses directly. Remote client workers download tasks via HTTP JSON from this server, perform health checks locally from their own internet connections, and return status metrics.
3. Does this server violate AUP regarding network abuse or scanning?
No. Since outbound port scanning is non-existent and bandwidth usage is minimal, this container will never trigger NetFlow alarms, firewall rate-limits, or ISP abuse notices.

VERCEL & SERVERLESS CLOUD PLATFORM COMPLIANCE (AUP)

1. Serverless Execution Lifecycle Compliance:
When deployed on Vercel Serverless (via `@vercel/python` or ASGI adapter), each API endpoint runs strictly within Vercel's standard HTTP execution lifecycle (< 10s-30s timeout). The application does not spawn unmonitored background daemons on Vercel edge.
2. Reverse Proxy IP Transparency:
The application natively parses and respects Vercel edge headers (X-Vercel-Forwarded-For, X-Real-IP, CF-Connecting-IP, and X-Forwarded-For), ensuring accurate client rate-limiting, HMAC validation, and zero IP spoofing.
3. Read-Only Filesystem & Ephemeral Storage Safe:
The engine automatically detects read-only deployment environments (such as Vercel Lambda containers) and transparently directs temporary session states to /tmp, completely avoiding runtime filesystem errors.
4. Automatic HTTP Polling Fallback:
For hosting providers or serverless platforms where persistent WebSockets are disconnected or unsupported, the web dashboard and client nodes automatically switch to adaptive HTTP polling (/api/stats, /api/tasks), ensuring 100% uptime with zero socket leaks.
